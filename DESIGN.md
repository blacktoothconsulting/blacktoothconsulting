# DESIGN.md

> Current visual design system for the Wyoming Clinic of Integrated Health website.
> Generated by the `/impeccable document` workflow. This file records *how the product looks and feels today* — the surface-level visual direction that can evolve across redesigns. Durable product facts (who it serves, what it does) live in `PRODUCT.md`, not here.
>
> Source of truth: `app/globals.css` (tokens), `app/layout.tsx` (fonts), and the components in `components/`. When those change, update this file.

## Design language

Warm-clinical and calm. A cool teal palette over near-white surfaces reads as clean and medical without feeling cold or corporate; a serif display face adds a local, established, trustworthy tone. Generous whitespace and a single accent hue keep the mobile-first surface uncluttered and easy to scan. Refinement over decoration — no gratuitous gradients, shadows used sparingly for lift.

## Color

Tokens are defined in `app/globals.css` in **OKLCH**, wired to Tailwind via `@theme inline`. Use the semantic token classes (`bg-primary`, `text-muted-foreground`, `border-border`, …) — never hard-coded hex/`text-white`/`bg-black`.

**Hue story:** one teal/cyan family (hue ~180) carries brand color; neutrals are subtly cooled toward the same hue (180–200) rather than pure gray. There is no competing secondary hue — emphasis comes from lightness/chroma steps of the single teal.

Light mode (`:root`):

| Token | Value | Role |
| --- | --- | --- |
| `--background` | `oklch(0.985 0.002 180)` | near-white cool page background |
| `--foreground` | `oklch(0.25 0.02 200)` | primary text; also the dark hero backdrop (`bg-foreground`) |
| `--primary` | `oklch(0.55 0.15 180)` | teal brand color — CTAs, icons, links |
| `--primary-foreground` | `oklch(1 0 0)` | text/icons on teal and on dark heroes |
| `--accent` | `oklch(0.45 0.12 180)` | deeper teal — link hover |
| `--secondary` | `oklch(0.95 0.02 180)` | tinted teal surface |
| `--muted` / `--muted-foreground` | `oklch(0.96 0.01 180)` / `oklch(0.5 0.02 200)` | quiet section backgrounds and secondary text |
| `--border` | `oklch(0.9 0.02 180)` | hairline dividers and card edges |
| `--destructive` | `oklch(0.577 0.245 27.325)` | errors only |
| `--radius` | `0.625rem` | base corner radius |

Dark mode (`.dark`): same hues, inverted lightness — `--background` `oklch(0.2 0.02 200)`, `--foreground` `oklch(0.95 0.01 180)`, and `--primary` lightened to `oklch(0.65 0.12 180)` so it stays legible on dark surfaces. Dark mode is class-based (`.dark` on an ancestor) via `components/theme-provider.tsx`.

Chart tokens `--chart-1..5` are teal monochrome steps (not a categorical rainbow), consistent with the single-hue system.

### Usage conventions

- **Icon chips:** an icon in a `bg-primary/10` circle (`rounded-full`, hero info cards) or rounded square (`rounded-lg`, service cards), sized `h-12 w-12`, with the glyph in `text-primary`.
- **Links in prose:** `text-primary underline underline-offset-4 hover:text-accent`.
- **Translucency on dark heroes:** overlays and outline buttons use `primary-foreground/NN` alpha (e.g. `bg-foreground/60` scrim, `bg-primary-foreground/10` button) rather than new tokens.

## Typography

Two families, loaded in `app/layout.tsx` via `next/font/google` as CSS variables and exposed as Tailwind classes in `@theme inline`:

- **`font-serif` — Playfair Display** (`--font-playfair`): all display headings (`h1`/`h2`/`h3`). Always `font-bold tracking-tight`, and `text-balance` on hero/section titles.
- **`font-sans` — Inter** (`--font-inter`): body, UI, labels. Body copy is `leading-relaxed` (and `text-pretty` for long descriptions). Set as the `<body>` default.
- **`font-mono` — Geist Mono**: available, not used in marketing surfaces.

**Type scale in practice:**

| Element | Classes |
| --- | --- |
| Hero `h1` | `font-serif text-4xl sm:text-5xl lg:text-6xl font-bold tracking-tight text-balance` |
| Page hero `h1` | `font-serif text-4xl sm:text-5xl font-bold tracking-tight text-balance` |
| Section `h2` | `font-serif text-3xl sm:text-4xl font-bold tracking-tight text-balance` |
| Card title `h3` | `font-semibold text-lg` (sans) |
| Eyebrow | `text-primary text-sm font-medium uppercase tracking-wider` |
| Body | `text-lg leading-relaxed` (hero) / `text-muted-foreground leading-relaxed` (sections) |

## Layout & spacing

- **Container:** `mx-auto max-w-7xl px-4 lg:px-8`. Reading-width blocks use `max-w-2xl`.
- **Section rhythm:** vertical padding `py-20 lg:py-28`. Alternate plain `bg-background` and quiet `bg-muted/50` sections for separation.
- **Section header pattern:** centered `max-w-2xl mx-auto mb-16` → eyebrow, then serif `h2`, then a muted description.
- **Grids:** `grid grid-cols-1 sm:grid-cols-2 lg:grid-cols-3 gap-6` for card decks. Use `gap-*` for spacing — never mix margin/padding with gap on the same element, and no `space-*`.
- **Spacing scale:** stick to Tailwind steps (`gap-4`, `py-6`, `mt-10`), not arbitrary values.
- Layout is flexbox-first; grid only for true 2-D card decks.

## Component patterns

- **Buttons** (`components/ui/button.tsx`, shadcn + CVA): primary CTA = default variant (`bg-primary`); `size="lg"` (`h-10 px-6`) for hero/page CTAs. On dark heroes, the `outline` variant is overridden to translucent (`bg-primary-foreground/10 border-primary-foreground/30 text-primary-foreground`). Icons are lucide-react, `h-4 w-4`, with `mr-2`.
- **Cards** (`components/ui/card.tsx`): `CardContent` padding `p-6`, hover lift `hover:shadow-lg transition-all duration-300`, edges `border-border/50 hover:border-primary/30`, leading icon chip on top.
- **Home hero** (`components/hero.tsx`): dark `bg-foreground` band, cross-fading image carousel (`transition-opacity duration-1000`) with a `bg-foreground/60` scrim, serif headline + eyebrow + dual CTA, animated pill carousel indicators, and a 3-up info-card strip (Location / Phone / Hours) on `bg-card` beneath.
- **Interior page hero** (`components/page-hero.tsx`): reusable `eyebrow`/`title`/`description`/`children`, dark with a `from-primary/25 via-foreground to-foreground` gradient, `py-20 sm:py-24 lg:py-28`.
- **Icons:** lucide-react throughout, `text-primary`, typically `h-6 w-6` in chips and `h-4 w-4` inline.

## Motion

Restrained and purposeful. Hero images cross-fade every 5s (`duration-1000 ease-in-out`); carousel indicators animate width/color (`duration-300`); cards transition shadow/border on hover (`duration-300`). `tw-animate-css` is available for utility animations. No scroll-jacking or decorative motion.

## Mobile-first & accessibility

- Every decision is judged at **~375px portrait first** (see PRODUCT.md); `sm:`/`lg:` progressively enhance.
- 44px minimum touch targets; text inputs ≥16px to prevent iOS zoom.
- Semantic landmarks (`section` with `id`, `header`, `main`), `sr-only` labels, and meaningful `aria-label`s on icon-only controls (e.g. carousel dots).
- Focus states come from the shadcn ring tokens (`focus-visible:ring-ring/50 ring-[3px]`); preserve them.
- All imagery uses `next/image` with descriptive `alt`.

## Guardrails

- Preserve the single-teal palette and the Playfair/Inter pairing — these are refinements, not a redesign (per PRODUCT.md).
- Only 3–5 effective colors on screen; introduce new shades as alpha steps of existing tokens, not new hues.
- Keep decoration load-bearing: no gradient blobs, no fake stats, no numbered markers on non-sequences.
- Route all color through semantic tokens so light/dark parity holds automatically.
